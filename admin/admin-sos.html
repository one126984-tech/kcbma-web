    데이터를 불러오는 중입니다...
    통화가 끊긴 뒤 10분이 넘도록 전문가와 다시 연결되지 않아 요청자가 운영진 확인을 요청한 상담입니다.
    아래 통화 기록(누가 언제 무엇을 눌렀는지)을 보고 판단하세요. 요청자 잘못이 아니면 [환불 + 처리 완료]를 누르세요. 선불 접수는 포인트로, 회원사·후불 접수는 청구에서 빼는 방식으로 자동 처리됩니다. 포인트 환불, 환불 장부 기록, 접수 '환불 완료' 표시가 한 번에 되고, 전문가 몫은 월 정산에서 자동으로 차감됩니다. 환불이 필요 없으면 [환불 없이 처리 완료]를 누르세요.

    불러오는 중...

    당번 날짜는 그날 21:00 ~ 다음 날 09:00입니다. 당번 전문가는 대기를 켜면 요청자 목록에서 우선 배치됩니다(요청자에게 당번 표시는 없음). 전문가 대기 화면에는 당번 안내가 나옵니다. 당번이 아니어도 누구나 심야에 대기를 켤 수 있습니다.
    심야에 대기 중인 전문가가 1명도 없으면 접수가 막히고 고객은 09시 연결 예약을 남깁니다. 아침에 아래 목록을 보고 먼저 연락해 주세요.

    불러오는 중...

    상담료와 연장 요금의 20%가 플랫폼 수수료, 80%가 전문가 지급액입니다. 초기 모집 전문가는 지정한 날짜까지 10%가 적용됩니다.
    끊김·연결불가 신고가 처리 중인 상담은 보류로 따로 표시되며 지급액에서 빠집니다. 환불된 상담은 환불한 달의 정산에서 전문가 몫과 수수료가 자동으로 차감됩니다. 지급액이 1만 원 미만(또는 차감으로 마이너스)이면 다음 달로 이월합니다.

    전문가별 정산표

    월을 고르고 조회를 눌러 주세요.

    초기 모집 수수료(10%) 적용 기간

    승인일로부터 6개월이 되는 날짜를 넣어 주세요. 비우고 저장하면 기본 20%로 돌아갑니다.

    불러오는 중...

    회원사 담당자가 회원사 센터에서 가입 신청 → 여기서 승인 → 담당자가 카드 등록(필수) → 건물 등록·직원 승인 순서로 진행됩니다. 카드 등록 전에는 승인해도 후불 이용이 시작되지 않습니다.
    매월 초 전월 이용 금액을 확인하고 등록 카드로 청구한 뒤 [결제 완료]를 눌러 주세요. 월 회비는 없습니다. 월 한도는 알림용이라 넘어도 접수를 막지 않습니다.
